连接 GitHub 仓库

为这个网站仓库授予 Contents 读写权限；审核客户评价还需要 Issues 读写权限。不勾选记住登录时，令牌仅用于本次页面连接。

仅在自己的设备上勾选。仓库、分支和令牌会保存在此浏览器，到期或退出登录时清除；令牌本身失效后需重新连接。

首次使用与本地编辑

本机双击“预览博客.cmd”，从网站底部进入管理页面，即可直接保存。在线使用时，先把项目上传到自己的 GitHub 仓库，再为托管平台配置 Git 仓库自动部署。EdgeOne 使用“导入 Git 仓库”；GitHub Pages 在仓库 Settings → Pages 中选择 GitHub Actions。

在线保存会提交到所选分支，托管平台重新构建完成后网站更新。此入口不预设公共管理员账号。
