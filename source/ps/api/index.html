在线 PS · 外部 AI 控制接口

给 aibot 或其他智能体使用的 HTTP JSON API。控制端会启动真实编辑器；AI 读取图层或截图、执行操作、核验结果，最后下载 PNG 或带图层的 PSD。接口不会直接接管你已打开的浏览器标签页，每个会话有独立文档。

接口状态（JSON） · OpenAPI 文档 · 打开编辑器

OpenAPI 文档可直接导入，无需先设置令牌；实际编辑仍需令牌。/ps/api/openapi.json 是 3.1 版；平台只接受 3.0 时改用 /ps/api/openapi-3.0.json，内容相同、版本号为 3.0.3。刚部署完静态文件可能有几分钟仍是旧缓存，此时可临时用 /api/ps-control?format=openapi（只接受 3.0 的平台加 &version=3.0），它由执行端实时生成。

1. 执行方式

同一个接口有两种执行端，由是否设置 PS_CONTROL_URL 决定，工具、鉴权和 OpenAPI 完全一致。

方式谁在跑编辑器需要什么
云端沙箱（默认）EdgeOne Agent 为每个会话启动独立 Chromium，通过 CDP 连接真实页面推送到 main 后由 EdgeOne 自动部署；无需常开电脑，无需环境变量
自建服务（可选）本机或服务器上的 npm run start:ps-api（Playwright + Edge/Chromium）一台持续在线的机器，并在 EdgeOne 设置 PS_CONTROL_URL

当前部署的方式可看 GET /api/ps-control 返回的 execution：edgeone-sandbox 或 external-worker。

令牌：仓库内置了当前令牌的 SHA-256 摘要，GET 可直接读状态，POST 需要 Authorization: Bearer <令牌>。令牌明文只保存在本机 work/ps-control/access-token，不上传 GitHub。要轮换，在 EdgeOne 环境变量设置 PS_CONTROL_TOKEN（24–512 个非空格 ASCII 字符）后重新部署，它会覆盖内置摘要，旧令牌立即失效。

自建方式首次启动同样生成 64 位十六进制令牌，连接信息写入 work/ps-control/connection.json（含 endpoint、token、openapi）。该文件也不上传。

2. 给 aibot 的调用流程

POST /api/ps-control
Content-Type: application/json
Authorization: Bearer <PS_CONTROL_TOKEN>

{"action":"create_session"}
# 返回 {"session_id":"...","viewport":{"width":1440,"height":960},...}

{"action":"list_tools","session_id":"..."}
# 返回 tools，每项含 name、description、inputSchema

{"action":"call_tool","session_id":"...","name":"create_document",
 "arguments":{"width":1200,"height":800,"name":"海报","background":"white"}}

{"action":"call_tool","session_id":"...","name":"add_text",
 "arguments":{"text":"你好，世界","name":"标题","x":80,"y":160,"size":64,"color":"#173e32"}}

{"action":"call_tool","session_id":"...","name":"get_document","arguments":{}}

{"action":"call_tool","session_id":"...","name":"export_file","arguments":{"format":"psd"}}
# 返回 result.name、mime_type、data_base64；base64 解码后保存文件

{"action":"close_session","session_id":"..."}

必须先读实时工具列表，再按 inputSchema 传参。工具错误是 HTTP 错误和 JSON error.message，不能当作编辑成功。一个会话内串行操作；同一会话并发调用会返回 409。默认最多 4 个会话，闲置 30 分钟后释放；关闭会话会回收对应浏览器。

排查失败时调用 {"action":"diagnose"}：它按顺序返回 sandbox、commands、cdp-url、cdp-connect、new-page、page 每一步的结果，最后一步 failed 就是问题所在。编辑失败返回的 error.code 为 CLOUD_EXECUTION_FAILED 时会附带 stage，指出卡在哪个阶段。

3. 可以控制什么

方式用途
结构化编辑工具新建、缩放、裁剪、旋转画布；绘画笔画、色块；查询字体；创建、编辑真实文字；图层移动、变换、复制、调色、显示隐藏；创建选区和真实蒙版；联网搜图与导入素材。
run_script执行编辑器兼容的 Photoshop 脚本：文档、图层组、路径、滤镜、混合、ActionDescriptor / executeAction 等。示例：{"code":"app.activeDocument.activeLayer.name = '标题';"}。这是编辑器脚本引擎，支持范围以编辑器为准；不是服务器任意 JavaScript，也不保证支持桌面 Photoshop 的所有 API。
inspect_ui / get_screenshot返回可见按钮与菜单的屏幕坐标，或编辑器截图。截图返回 PNG base64，调用方须将其作为图片发给支持看图的模型。
ui_action操作其余界面工具：click、double_click、move、drag、scroll、key、type。坐标为截图的 CSS 像素；画布工具使用的坐标则是文档像素，两者不能混用。例：{"action":"key","key":"Control+z"}；拖动需给 x、y、to_x、to_y；输入文字需先聚焦输入框。
open_file / export_file上传 base64 图片或 PSD 作为文档打开；导出 PNG、JPG、PSD。PSD 保留真实图层、文字和蒙版。普通图片不会自动恢复原始分层。上传文件名不含路径，base64 不带 data: 前缀。
list_documents列出当前会话文档。可以通过脚本切换文档与复制图层。
configure_image_ai可选：给这个会话设置生图模型，然后调用 generate_image 或 generate_layered_image。type 为 images / chat / gemini，url 是平台根接口地址，model 是准确模型 ID，key 是平台 Key，proxy 可解决跨域。Key 只保存在当前会话内存。外部 aibot 本身负责操控时，无需再填操控模型。
{"action":"call_tool","session_id":"...","name":"configure_image_ai",
 "arguments":{"type":"images","url":"https://你的平台/v1","model":"你的生图模型","key":"你的模型Key","proxy":true}}

{"action":"call_tool","session_id":"...","name":"ui_action",
 "arguments":{"action":"drag","x":500,"y":400,"to_x":700,"to_y":600}}

{"action":"call_tool","session_id":"...","name":"open_file",
 "arguments":{"name":"photo.png","data_base64":"<文件base64>"}}

推荐给 aibot 的工作规则：先检查文档和实际字体，分别创建背景、主体、装饰和文字；不要用空图层或改名冒充分层。每几步读一次图层状态和截图核验，完成后导出 PSD 和 PNG，再关闭会话。UI 操作前先观察界面，脚本与鼠标键盘操作也需要核验结果。

4. 接到正式网站

默认不需要任何环境变量：推送到 main 后，EdgeOne 用 edgeone.json 的 agents 段启动沙箱运行环境，执行端在 /ps-control-worker，由 /api/ps-control 转发。网站只提供入口和鉴权，真正的浏览器运行在平台沙箱里。

aibot 接口地址：https://senkou.xyz/api/ps-control
OpenAPI：https://senkou.xyz/api/ps-control/openapi.json
（静态副本 https://senkou.xyz/ps/api/openapi.json 同样可用）
请求头：Authorization: Bearer <令牌>
请求头：Content-Type: application/json

需要改用自己的服务器时，在 EdgeOne 生产环境变量里填写下表并重新部署，入口会自动切到外部 worker，改动代码不需要。

EdgeOne 环境变量填写内容
PS_CONTROL_URL浏览器服务可访问的 HTTPS 根网址，例如 https://worker.example.com；不是本网站的 /ps/ 页面，也不能指回同一个转发入口。设置后不再使用云端沙箱。
PS_CONTROL_TOKEN访问令牌，与 aibot 的 Bearer 一致；不设时使用仓库内置摘要对应的令牌。

网站入口和执行端分别校验 Bearer 令牌。没有令牌或令牌错误时，操作请求返回 401；入口不能用时操作返回 503，状态为 ready:false。状态和接口说明可公开读取，不授予编辑权限。不要将令牌放在网址、公开文档或 GitHub 中。

限制数值说明
单次请求体5 MBbase64 会膨胀约 1/3，上传图片建议先压到 3.5 MB 以内；超限返回 413。
单次执行120 秒建会话、打开编辑器、导出都要各自完成；复杂任务拆成多次调用，超时会话即关闭。
会话数量 / 空闲4 个 / 30 分钟闲置超时会回收沙箱；重新调用需先 create_session。
导出体积不受 5 MB 限制已实测 13 MB base64 的 PNG 可以正常返回；大 PSD 请直接下载 base64 结果。

可调环境变量：PS_CONTROL_URL、PS_CONTROL_TOKEN、PAGES_BASE_URL（沙箱打开的编辑器正式网址）。自建服务另有 PS_CONTROL_PORT（默认 4010）、PS_CONTROL_HOST（默认 127.0.0.1）、EDITOR_BROWSER_CHANNEL；关闭进程可回收全部浏览器会话。

5. 可运行的客户端

仓库内运行 node examples/ps-control-client.cjs。示例读取本机连接文件，创建色块和中文文字，再把 PNG、PSD 写入 work/ps-control-example/。也可用环境变量 PS_CONTROL_ENDPOINT 与 PS_CONTROL_TOKEN 指定远程接口。

运行 npm run test:ps-api，检查真实浏览器编辑、PSD 往返、鉴权、会话隔离、云端执行端的错误路径与网站转发。
